# Expense Tracker Flutter App with Shared Preferences

This is a simple Expense Tracker app built using Flutter and Shared Preferences for local data storage. The app allows users to track their expenses, categorize them, and view their spending history. The UI is clean and intuitive, making it easy for users to manage their finances on the go.

## Features

- **Expense Management**: Users can add, edit, and delete expenses with details like amount, category, date, and description.
- **Local Data Storage**: All expense data is stored locally using **Shared Preferences**, ensuring data persistence even when the app is closed.
- **Expense Categories**: Expenses can be categorized (e.g., Food, Transportation, Entertainment) for better organization.
- **Expense Summary**: The app provides a summary of expenses, including total spending and breakdown by category.
- **Responsive UI**: The app features a clean and responsive design that works well on both **Android** and **iOS** devices.
- **Date Filtering**: Users can filter expenses by date (daily, weekly, monthly) to track spending over time.

## Technologies Used

- **Flutter**: Framework for building cross-platform mobile applications.
- **Shared Preferences**: For local storage of expense data.
- **Intl Package**: For date formatting and localization.

## Setup and Installation
- **Flutter Version Used**: 3.22.3 

### Follow these steps to run the app:
-   git clone https://github.com/Laraib-Memon3/expense_tracker_flutter
-   cd Expense_tracker_flutter
-   flutter pub get
-   flutter run
